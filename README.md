# Ollama Parity Model Test

Проект демонстрирует автоматизированную проверку ML-модели с использованием метрики accuracy.

Сценарий работы:

1. Скрипт отправляет запрос в Ollama.
2. Ollama генерирует 100 целых чисел и указывает для каждого:
   - `even` — чётное число;
   - `odd` — нечётное число.
3. Полученные данные используются для обучения модели `scikit-learn`.
4. После обучения Ollama генерирует ещё 100 чисел.
5. Обученная модель определяет чётность новых чисел.
6. Результаты сравниваются с метками от Ollama.
7. Рассчитывается точность модели с помощью `accuracy_score`.

Пример результата:

```text
Точность модели: 100%

Требования
- Python 3
- Ollama
- модель llama3.2:latest
- scikit-learn

Установка
pip install -r requirements.txt

Убедитесь, что модель Ollama доступна:
ollama pull llama3.2:latest

Запуск
python train_parity_model.py

Файлы проекта
- train_parity_model.py — основной скрипт
- requirements.txt — зависимости проекта
- README.md — инструкция по запуску

Зависимости
ollama
scikit-learn

Примечание
Данные для обучения и тестирования генерируются LLM через Ollama.
Так как LLM может нестабильно следовать требованиям формата, скрипт использует
структурированный JSON и проверяет количество полученных записей.
